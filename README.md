# 辽宁大学 GPA 计算器

使用 Python 3.10 或更新版本，无需安装额外依赖。

```sh
python -B app.py
```

打开 http://127.0.0.1:8765/。复制学校教务系统「全部及格成绩」页的内容并导入，或手动添加课程。核对课程名、学分、成绩和修读方式后，点击「计算汇总」。

教务导入默认将修读方式设为「正常」，可以在课程表改为「补考」或「重修」。教务页面遗漏的课程或考核记录请手动补录。计算结果仅供参考，以教务系统实际显示为准。

## 计算口径

- 正常修读数字成绩按原截图的 60–99.5 分表逐项查找，100 分为 4.00，60 分以下为 0。60 分及以上的正常成绩若不满足 0.5 分步长，要求人工核对，不插值、不擅自舍入。
- 正常修读五级分制：优秀 4.00、良好 3.00、中等 2.00、及格 1.00、不及格 0.00。正常修读两级分制：合格 3.00、不合格 0.00。校对时请区分「及格」和「合格」。
- 重修、补考的通过成绩统一算 1.00，未通过算 0.00；数字成绩以 60 分为通过线。
- 大学英语四级、六级连同其学分全部排除。普通课程「大学英语（四）」保留。
- GPA = Σ(绩点 × 学分) ÷ Σ有效课程学分。修读总学分等于这个分母，包含计入的未及格课程学分；不等同于已取得学分。每行按一条课程记录统计；程序不会自行选择多个成绩记录中的哪条。
- 学分加权平均分由未舍入的 GPA 反推：`X = 100 − √(1600 × (4 − GPA) ÷ 3)`，显示三位小数。等级成绩、补考和重修均按各自的绩点规则参与 GPA，再统一换算。公式仅适用于 `1 ≤ GPA ≤ 4`，对应 `60 ≤ X ≤ 100`；GPA 超出范围时平均分显示「—」，GPA 照常显示。有效学分为 0 时，GPA 和平均分均显示「—」。
